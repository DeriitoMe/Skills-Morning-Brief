# tibo监视

本专栏只跟踪 ChatGPT / Codex 额度刷新、补发、可储存重置及其操作方式。原文没有明确的重置时刻时显示未明确，不把发帖时间、下一次监测时间或一句“明天见”当作账户重置时间。

## 来源与核对

公开 RSS 和公开页面只用于发现 `thsottiaux` 的帖子标识。正文、日期及作者由 X 官方发布接口再次核对，镜像正文与时间不作为发布依据。接口只返回日期或截断文字时明确标注。每轮最多处理最近 20 个链接、核对 8 条原帖，未读取候选在后续轮次继续核对，已发表相关原帖优先复查。

可选的 X API 读取当前目标公开账号的最近帖子，凭据来自 `X_BEARER_TOKEN` 或 `TWITTER_BEARER_TOKEN` 环境变量。私有或无法确认公开属性的账号不读取；令牌只进入固定 X API 域名的请求头，不保存到数据文件、不进入前端、不随重定向转发。当前环境没有配置该凭据，官方 API 路径通过受控样例验证，真实授权调用未验证。

官方资料来自 OpenAI 的更新日志、定价与用量说明、可用重置说明。历史功能上线说明保留原发布日期，未注明日期的规则说明单独展示。页面结构变更或访问失败时保留上次核对结果，显示当前访问状态。

## 记录与去重

消息保存原帖或官方链接、发布日期及精度、首次采集时间、最近核对时间、机制、执行状态、适用范围及待确认事项。原帖身份用于去重，相同日期的重复正文合并；下一日相同文字可以作为新的消息。来源明确指向同一事件且时间或重置表述相矛盾时标为待确认。含糊回复、未读取的长帖部分及无法验证的二手线索不作确定结论。

公开文件 `data/public/tibo.json` 和分发快照 `seeds/tibo.json` 使用字段白名单，不包含原始采集响应、私有画像或密钥。核对缓存在 `data/cache/tibo/`，运行记录在 `.runtime/tibo-runs/`，均不分发。网站独立提供公开的 `/api/public/tibo`，无需建立个人方案。

## 12 小时监测

- 08:30：现有 `Skills Morning Brief - Daily` 执行所有公共监测并包含本专栏。
- 20:30：`Skills Morning Brief - Tibo Evening` 只核对本专栏，不重复其他 Skills 的 AI 编辑。

时间为 Asia/Shanghai。电脑开机、当前用户登录时执行，错过触发后补执行。两项任务共用项目互斥锁。`scripts/setup-schedule.ps1` 注册两个时点；单独注册晚间任务可运行 `scripts/setup-tibo-schedule.ps1`。

手动核对：`python -m morningpaper tibo-monitor`。网站每分钟读取一次本机已更新的专栏快照。该读取不是 X 实时监测，也不发送邮件或手机通知。

## 验证与回滚

新增测试覆盖相关性筛选、作者核验、日期精度、未来与已完成重置的区分、告别语与实际重置时间的区分、去重、同事件冲突、缓存轮换、接口失败保留及私有字段过滤。实际运行证据另存本机运行目录，不写入公开报告中的私人路径或凭据。

需要暂停晚间核对时，在 Windows 任务计划程序禁用 `Skills Morning Brief - Tibo Evening`。源码使用正常提交，可回退到 v1.0.0；保留当前 OS 用户的资料目录。旧版不包含晚间专栏命令，回退前先禁用新增任务。v1.0.0 标签与 Release 保留不变。
